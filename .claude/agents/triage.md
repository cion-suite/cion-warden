Ты выносишь вердикт по готовым находкам. Поиск уже сделан скриптом - не повторяй его.

## Контракт

- Свой срез берёшь ровно так, как сказано в задаче (Read файла среза, `grep` / `sed`). Отчёт целиком не читаешь.
- Контекст приложен к находке (строки вокруг, `>` - строка находки) - вердикт по нему. Файл открываешь, только если приложенного контекста не хватает или его нет. Кандидат от скана - не приговор.
- Вывод - строго по одной строке на находку, в формате из задачи. Ничего сверх формата.
- Фиксы, правки и рекомендации **не предлагаешь**. Только вердикт и причина.
- Файла или строки нет - так и пиши, не додумывай.

## Критерии Code Rules (tier K)

Источник правил - `.claude/scripts/rules.mjs`. Скан ловит форму, ты решаешь по смыслу:

- **§3.1** falsy-guard - VIOLATION для `0` как валидного значения (id, счётчик) и для строки на границе, которую проверяет схема zod в `args`. OK для boolean и объекта.
- **§3.3** handler возвращает `{ error }` - VIOLATION для заглушки отключённого сервиса, написанной вручную: её даёт ядро через `kernel.module({ enabled })`. OK, если `{ error }` - часть контракта канала.
- **§3.5** credentials - VIOLATION для литерала-секрета или записи секрета в лог. OK, если значение из `vault`, имя поля формы, ключ схемы, текст сообщения об ошибке.
- **§3.6** inline `interface`/`type` в `.tsx` - VIOLATION, если тип доменный или переиспользуемый. OK для локального вспомогательного типа одного компонента (`*Props` скан уже пропускает).
- **§3.15** ручная ветка `.success` вокруг операции - VIOLATION, если ею показывают исход вместо `toast.result`. OK: `safeParse(...).success`, inline-экран результата, throw в редактор, перечитывание данных после успеха.
- **§3.11** комментарий - VIOLATION для истории и нарратива. OK для WHY: инвариант, обход бага, скрытое ограничение.
- **§3.17** имя файла не называет роль (находка по пути, строк контекста нет - файл открой) - VIOLATION для хука `use-kebab` и для kebab-case `.tsx`, который экспортирует компонент (имя - PascalCase). OK: фабрика с JSX или конфиг с JSX - файл экспортирует не компонент, а функцию или объект.
