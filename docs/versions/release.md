### Версия v1.0.0

#### Важно знать

- Приложение переведено на скрипты AutoHotkey v1: вместе со скриптом загружаются его конфиг и общие файлы источника, пресеты берутся из файлов .ahk.
- Значения из прежнего формата не подхватываются и заданы заново; скрипты, которых больше нет в источнике (delay, endo_nidus), удалите вручную, а старые файлы значений и кеша остаются на диске без использования.
- Обновление перезаписывает скрипты, библиотеки и пресеты целиком: ручные правки в них теряются. Наличие обновления определяется по версии скачанного файла, поэтому ваши правки обновлением не считаются.

#### Скрипты и бинды

- Скрипты запускаются найденной в системе установкой AutoHotkey v1, при её отсутствии показывается ошибка; скрипт, перезапущенный изнутри, остаётся в статусе запущенного.
- Окно настройки скрипта и форма пресета показывают секции, подсказки и горячие клавиши из файла и сохраняют значения прямо в нём; поля разделены на вкладки "Значения" и "Бинды" (если есть и те, и другие); кнопки сброса больше нет.
- Горячая клавиша или кнопка мыши записывается нажатием: контекстное меню не открывается, переход назад не срабатывает.
- При обновлении скрипта или пресета ваши значения переносятся в новый файл по имени переменной: поле, которое вы не меняли, сохраняет прежнее значение, а не новое из репозитория; выражения (например, false или A_ScreenWidth) берутся из новой версии.
- Ошибка загрузки конфига прерывает установку скрипта, а скрипт без скачанного конфига помечается как требующий обновления.
- При удалении скрипта удаляется его конфиг, а общие файлы - вместе с последним скриптом источника.

#### Библиотеки и источники

- Массовая синхронизация библиотек не перекачивает актуальные файлы и не затирает ваши правки в них.

#### Обновления

- Добавлен раздел "Что нового" с логом версий и окном после обновления приложения.
- Обновления приложения берутся из GitHub Releases: проверяются оба репозитория релизов, устанавливается самая новая версия.

#### Интерфейс

- Обновлён вид уведомлений и элементов интерфейса: меню, списки, диалоги и подсказки.
