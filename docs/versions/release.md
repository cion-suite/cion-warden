### Версия v1.0.0

- Добавлен раздел "Что нового" с логом версий и окном после обновления приложения.
- Добавлена палитра команд для быстрого перехода по разделам, смены темы и языка.
- Добавлен выбор канала обновлений: стабильный или бета.
- Оптимизирована внутренняя архитектура приложения.
- Обновлён вид уведомлений и элементов интерфейса: меню, списки, диалоги и подсказки.
- Добавлена загрузка общих файлов скриптов источника и конфигов формата AutoHotkey v1 вместе со скриптом.
- Скрипты запускаются найденной в системе установкой AutoHotkey v1, при её отсутствии показывается ошибка.
- Исправлен статус скрипта после его перезапуска изнутри: он остаётся запущенным.
- При удалении скрипта удаляется его конфиг, а общие файлы - вместе с последним скриптом источника.
- Пресеты биндов берутся только из файлов .ahk.
- Наличие обновления скриптов, библиотек и пресетов определяется по версии скачанного файла: ваши правки в нём больше не показываются как обновление.
- Массовая синхронизация библиотек не перекачивает актуальные файлы и не затирает ваши правки в них.
- Ошибка загрузки конфига при установке скрипта теперь прерывает установку: скрипт не остаётся без конфига.
- Значения пресетов биндов сохраняются прямо в файле .ahk пресета.
- При обновлении пресета ваши значения переносятся в новый файл по имени переменной; выражения (например, false или A_ScreenWidth) берутся из новой версии.
- Из формы пресета убрана кнопка "Сбросить": исходных значений без файла больше нет.
- Значения пресетов из прежнего формата не подхватываются и заданы заново.
